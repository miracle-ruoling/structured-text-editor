# 3B：合并写作与结构工作台

2026-10-21 用户反馈并授权：3A 界面过于独立，写作应直接融入原工作台；先支持文档大标题、新段落类别选择、默认标记，以及导入 DOCX 的显式文字编辑。

## 本轮契约

- 统一使用现有工作台及类别/标签、筛选、格式、模板面板。新建空文档默认可写；导入文档默认只读，顶部「启用文字编辑」启用后持久保存。
- 文档大标题使用 title 类别，与 heading 小标题及其层级分开；正文、三级小标题、大标题可在新段落菜单选择，其他现有类别保留。
- 回车拆出新段落，在新段落旁显示类别容器，正文默认框选；数字选择对应类别，左右键循环，回车确认当前段落类别，不额外插入空段。普通文字输入直接进入正文并收起容器，Escape 收起；鼠标选择不夺取正文焦点，中文组合输入不触发菜单快捷键。
- 默认显示类别/标签，沿用「标记」按钮；编辑光标与格式筛选范围独立，点标记仍可选范围，点文字编辑不暗改批量范围。
- 已启用编辑的 DOCX 在独立内容快照中保存修改，原 source.docx 永不覆盖；新段落采用单调递增稳定 ID，删除/插入不重编号旧段落。表格普通段落可改字，图片/公式/域/超链接等复杂段落保留只读，不降级成纯文本。
- 正文操作、标注、格式、模板共用现有持久撤销/重做。文字自动保存；未保存/失败状态可见，失败保留本地输入，其他会改变文档的操作等待保存完成。
- 编辑模式不运行旧的原文字完整性导出审计，隐藏「导出检查」，直接生成已保存编辑结果；未启用时保留原审计。正常项目校验、版本冲突检查与 ZIP/未修改部分保留仍有效。
- 3A 原生备份和本机原生文档进入统一工作台，保留旧文件，迁移内容及可用历史，不静默丢弃。
