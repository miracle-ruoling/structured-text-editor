## F. 本轮反馈修复验收

1. 刷新/重新打开页面：初始显示「未筛选」，没有绿色高亮。点正文预设后出现匹配；退出筛选或逐个删除最后一条条件，回到未筛选；「全部内容」才明确全选。空条件未填完时不选取任何段落。
2. 点击一个段落，对象框为紫色；切回批量操作页隐藏紫色框，回对象页/退出筛选恢复原对象。对象检查不会加入筛选范围。
3. 对象类别选「引用」后立即保存。输入标签后 Enter/+ 即保存，× 即移除，无「保存标注」二次按钮；逐次撤销可还原。只加标签不会把自动类别标记成手工确认。
4. 筛选标签或文字字体已经选中一个值后，再次展开仍可看到其他全部候选。点「自定义…」能输入新值。
5. 文字页设置字号 18，段落页设置缩进 2：默认预览只改段落；勾选同时应用文字页才把字号一起带入。未勾选时摘要不能出现字号。
6. 预览时命中段落显示绿色「修改前」与蓝色「预览后」。用大按钮或 Esc 退出后草稿保留。成功应用后两页草稿都清空；勾选锁定再应用，草稿保留并可换范围使用。
7. 有格式草稿或未添加标签时切换文档会弹窗；取消留在当前，确认后切换并清空。没有草稿时不重复询问保存。已有操作已自动保存。只切换检查对象时，仅未添加标签会触发提示。
8. 连续导出项目包不应增加最近项目。重复导入同一个 DOCX 应回到原项目及其修改；重复导入相同项目包快照不新增同状态项目。不同快照保留为名称有区分的新项目；旧同名条目用日期、修订和短 ID 区分，不删除旧内容。
9. 打开「东南大学物理实验报告（电子版）.docx」，查看开头「实验报告格式要求」段。应完整显示在阅读区域内；对象属性保留左右 3 字符、首行 -9 字符的原始值。缩放/窄窗口也应可阅读；导出不修改未选中段落。
10. 使用新示例确认原 A—E 仍通过。导出入口已更名「导出项目包」，标注步骤不再需要手工保存按钮。

## A. 核心缩进场景

1. 点击「打开一份新示例」。
2. 选择「正文 · 排除例外」：预期命中 **5** 段，编号 **03、05、06、09、21**。
3. 首行缩进设置 2 字符，点击「预览修改」。
4. 预期只有这 5 段显示蓝色预览状态；小标题、表格内文字、编号 07 的保护段落不变。
5. 退出预览，预期文档回到原显示；再次预览并应用，预期提示已修改 5 段。
6. 撤销、重做各一次，预期整次操作一起还原/恢复。

## B. 类别和标签

## C. 其他格式

1. 选择所有小标题，进入「文字」，点击「四号 14」。
2. 预览、应用，检查只有小标题字号变化。
3. 选择表格内文字，设置居中、段后 0 磅，检查表格以外不受影响。
4. 组合两个互斥条件，应显示 0 匹配并禁用格式应用；改成「任一条件」后应正常匹配并集。

## D. 保存与恢复

1. 导出项目包，刷新页面，确认已经应用的格式和标注仍在。
2. 导入保存的 `.sdoc`，确认类别、标签、格式和撤销历史都在。
3. 打开新示例后，通过「打开最近文档」切回先前项目。
4. 预览期间刷新页面，预期不会把预览草稿当作已应用修改。

## E. 真实 Word 文件

1. 导入一份自己的 `.docx`，先检查自动分类，修正未知或错误类别。
2. 选择正文，排除表格和例外标签，设置首行缩进并导出 Word。
3. 在 Word 中确认内容、图片/公式、表格与页眉页脚保留，且选中范围准确。
4. 注意：字号/行距变化会引起重新分页，这是实际排版变化；本工具不承诺页面像素一致。
