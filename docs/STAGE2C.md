## 一、相对字号的明确语义

单次格式面板增加字号模式：统一设为、增减磅数、中文字号增减级数。磅数步进 0.5；中文序列从小到大为八号 5、七号 5.5、小六 6.5、六号 7.5、小五 9、五号 10.5、小四 12、四号 14、小三 15、三号 16、小二 18、二号 22、小一 24、一号 26、小初 36、初号 42。非标准字号向指定方向取下一个严格更大/更小的档位，例如 13 磅增一级为 14、减一级为 12，不先四舍五入。

基准是当前已保存、已计算规则和局部覆盖后的每个文字 run，而不是取全段平均值。按磅增减保留数值差，中文档位可能将不同字号映射到同一档；空段落使用可解析的段落标记字号。未知字号或超出允许范围时整次操作拒绝，提示具体段落，用户可改用绝对字号，不猜测、不静默截断。

领域层增加一次字号变换请求与局部逐 run 结果。run 用源段落内直属普通 w:r 的稳定索引定位，段落标记单独保存。结果是冻结的绝对局部覆盖，后续规则不会让它反复增长；重复执行单次操作才继续增减。相对请求不进入持续规则。预览采用完整 after_blocks，与最终写入相同计算。清除字号局部覆盖同时清除逐 run 结果，恢复下层。

项目 schema 升级 v4，兼容 v1/v2/v3，旧历史补空字段；导入检查 run 索引属于当前源段落。绝对字号新操作会替换旧逐 run 字号。快照、项目包往返和去重使用完整 Annotation。

## 二、Word 读取与可写属性

- 按文档关系读取主题、设置和编号 XML；只读取包内资源，不访问外部目标。
- 解析 major/minor 的西文字体及常见东亚语言补充字体；遵循主题引用与直接字体的优先级，未知主题仍保留为未知。补充字符样式的粗斜体 toggle 继承、段落直接 false、单位替换和混合 run 来源。
- 读取编号实例、级别、格式、模板及起始值/覆盖，合并编号级别的段落格式。编号字形自身的 rPr 不误当正文格式；不重建自动编号，不承诺浏览器重现编号序列。
- 读取大纲级别、Word 分节、段前分页、与下段同页、段中不分页和孤行控制。新增粗体/斜体及上述四个分页开关的显式设置，规则与单次操作都可使用；三态输入区分不设置、开、关，导出 false 必须显式写 0 以覆盖继承。
- 精确/最小行距继续以原始单位显示，并区分类型；更多复杂表格条件样式、网格与完整分页仍保留明确边界，不伪称已支持。

## 三、章节与分节选择

章节由表格外小标题及原 Word 大纲级别构成，包含标题自身及其子章节；手工改类别后重新计算，手工新建的小标题无原级别时按一级处理。标题前内容为「前言区域」。表格内的小标题不截断外部章节。Word 分节按源 sectPr 确定，段落中的分节符属于结束的那一节。

增加 chapter/section 条件，与类别、标签、位置和高级表达式组合，也可存为规则。章节 ID 基于标题段落；分节 ID 基于源文件次序，属于当前文档，不能跨文件复用。左侧折叠章节导航、条件下拉和对象信息显示范围；章节层次与 role/tags 仍分离。

## 四、导出差异与兼容性说明

新增「导出检查」入口，展示当前已保存状态的结果，不作为每次导出的强制确认。后端生成实际 DOCX 后比较源包：改动的段落及属性、变化的 ZIP 项、保留项数量、正文文本是否保持、未计划修改的段落是否变化。检查与写入在 DOCX 适配层，HTTP 层不拼 XML。报告可下载 JSON，包含 revision 和源文件散列以定位版本。

报告同时说明原文件中只能保留/近似显示的结构、字号或间距导致重新分页的正常影响，以及尚未解析的属性。若发现非预期段落/非 document.xml 项或文本变化则阻止该次导出并报错，不能用报告掩盖保留失败。规则、逐 run 覆盖和普通补丁共用同一导出路径。
