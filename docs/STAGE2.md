## 2A：可复用的选择范围（已通过）

### 类别来源简化

自动识别与手动设置在格式操作中地位相同，没有必需的确认步骤。去掉“等待确认/已确认”的界面状态，仅显示来源。保留手动覆盖数据，以免将来识别器改进时覆盖用户意图；提供“恢复自动识别”，可撤销，不改变标签或格式。无需先切到其他类别再切回。

### 高级逻辑

保留简单模式的“全部/任一”。高级开关显示条件代号和表达式输入，例如 `$A AND ($B OR NOT $C)`；支持 `AND/OR/NOT`（不区分大小写）与括号，优先级 NOT > AND > OR。代号以 `$` 开头，与条件内容严格分离，无正则、无 eval。

每个条件有稳定代号，删掉 B 不会让 C 自动变成 B。删除被引用条件后必须明确报错，绝不能默默改选其他段落。允许暂时有未引用条件但显示提醒；非法/空表达式清除命中并禁用预览。简单/高级切换显式改变组合方式，切换后旧预览失效。后端统一解析和求值；前端只管理输入和完整性，不另写一套命中算法。

新模块 `domain/expressions.py` 使用受限词法扫描、递归下降解析、长度/深度限制和缓存。嵌套 all/any API 保持兼容。命中、预览、提交都使用同一选择器，未知代号和非法语法拒绝请求。

### 显式鼠标范围与单对象入口

阅读区增加“框选”开关；启用后段落旁显示复选框，可逐个勾选。鼠标检查焦点、框选集合、绿色筛选命中分别显示。仅勾选不自动扩大格式操作范围；点击“加入筛选条件”才复制当前 ID 集合，条件保存的是快照，之后勾选不改变它，快照不可原地更新，需删除旧条件后重新加入。

范围条件可与角色/标签/位置/文字自由组合，支持“是/不是”，空快照不允许提交。复杂只读段落不可勾选。切换文档清空框选；同文档标注/撤销保留框选。对象页“仅调整此段”使用同一个格式面板和仅含该 ID 的选择器，避免第二套格式写入实现。

### 命名筛选

当前文档可保存最多 50 个命名筛选（只存条件，不存格式草稿、不持续改文档）；名称非空且不重名。左侧列表可恢复或删除，删除可撤销，不再确认。新建名称在显式保存前是草稿，切换文档保护。

存入项目而非浏览器 localStorage；项目包携带，刷新和重新导入可恢复。project schema 升至 v2；v1 读入时兼容升级，旧撤销快照补空集合，新快照同时记录标注与命名筛选。源 DOCX 不变。项目包相同状态复用判断包含新集合，避免把不同集合误认成同状态。

### 验证与交付

自动检查表达式真值/优先级/非法输入/引用稳定性、范围排除只读对象、保存与撤销/迁移/项目包往返、单段修改的 ZIP 和未选中段落保留。前端纯状态测试范围快照与稳定代号，TypeScript/Vite 检查。浏览器使用实际可用工具，若仍有权限拒绝则记录，不能宣称完成点击验证。

更新 STATUS/ARCHITECTURE/ISSUES，详细 Git 提交，不推送。用户只需检查本次新增功能和类别来源调整，不提供重复回归清单。
