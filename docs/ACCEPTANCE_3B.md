# 本轮交付：统一写作工作台

新建文档即可在原工作台编辑；导入文档点顶部「启用文字编辑」后可改字。文档大标题已支持。回车新段落出现类别容器：正文默认框选，数字/左右键切换，回车确认，鼠标点击也不夺走正文光标。标记默认显示，可沿用原按钮关闭。

编辑后共用原有筛选、格式、标注、模板与撤销重做，Word 导出不再运行“文字不得变化”的检查。图片/公式/链接等复杂段落仍保留且文字只读；本期不含完整复杂文档编辑。

开发侧已完成 137 项后端、46 项前端回归及构建、Ruff、浏览器交互与桌面布局检查。用户只需审查本次写作整合，无须重复执行旧回归。

关闭旧启动窗口后运行 Start.cmd 并刷新页面，才能加载新后端接口。本轮结束暂停验收。
