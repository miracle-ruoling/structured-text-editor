# 3C：多段粘贴写作

2026-10-21 用户确认非空文档编辑修复成功，并授权下一阶段。本期先交付多段粘贴，作为跨段写作的第一步；不将跨段拖选替换或复杂对象编辑计入本期。

## 契约

- 在一个可编辑段落内粘贴纯文本，替换当前段内选区或插入到光标处。CRLF/CR 统一成 LF，每个粘贴换行新建一个正文段落，保留连续空行和尾部空行；原文已有软换行不拆段。Shift+Enter 仍是段内换行。
- 首段保留 ID、类别、标签与段落格式。新增段落使用新稳定 ID 和正文默认格式，不复制首段标签/标题类别；未选中前后文字的 run 格式保留。粘贴内容不携带外部 HTML 样式。
- 文档主体和表格单元格使用同一机制，新段留在原容器内。复杂段落继续只读；跨段选区粘贴明确拒绝，不删除任何原文。
- 一次粘贴只提交一次内容快照、一次历史、一次原子保存；操作前的本地草稿先保存，其历史独立。撤销/重做还原所有新增段落及标记。稳定 ID 分配器不回退。
- 粘贴成功后光标置于最后插入文字之后、原后缀之前，不打开类别选择容器。等待请求期间暂停本段输入；失败保留粘贴文本和位置，可重试/下载，放弃需确认。未完成前禁止切换/导出等会隐藏或改变文档的操作。
- 偏移按 Unicode 码点；服务端校验选区、文字控制字符、20,000 段上限，以及本次插入和原段合计 100,000 字符上限。权限/书签/校对/分页元数据保留并映射到新位置，源文件与未修改部件不变。

## 验证

自动检查段内替换、多段/空行/尾行、emoji 偏移、原软换行、类别、ID、一次撤销重做、项目包恢复、表格边界、只读对象、未选中 run 和范围标记、未修改 ZIP 部件、非法请求不落盘。浏览器验证多段粘贴及续写光标、撤销重做、刷新恢复和失败重试。

本期结束后暂停验收。下一期候选仍为跨段选区与复杂节点，不自动开始。
