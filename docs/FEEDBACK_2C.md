## F1 操作语义

- 默认字号输入为绝对磅数；两个 A 上/下箭头按钮按中文字号序列增减。取消模式下拉与相对数值输入。API 的按磅增减能力保留兼容，常用界面不暴露。
- 没有绝对草稿时，按钮以已保存各 run 为基线累计净增减级数；例如连续 +、+ 是 +2，随后 − 为 +1，净零回到原格式。输入绝对字号后按钮调整该统一值；手动输入替换相对动作。混合范围用“混合字号”占位，并可看净级数摘要，不假造统一大小。
- 应用成功清空全部格式草稿，无锁定保留开关。取消/Esc 清空本次单次格式草稿并恢复已保存视图；已应用结果使用撤销。分组折叠不提交、不丢草稿，分组显示已填项数、底部始终显示全部提交摘要；统一应用所有填写的属性。
- 文字/段落都是原生可折叠区；默认文字展开，段落收起，分页为段落内次级折叠。暂不引入多浮窗/独立提交栈，避免隐藏草稿和关闭确认。规则编辑暂复用分组，但保留旧规则的显式预览保存流程，待 F2 完整替换。
- 单次格式输入后约 180ms 合并请求，预览不持久化、不写历史。输入可持续操作，不用全局 busy 锁预览。每次最多一个预览请求在途，只保留最新待算请求；过期响应不覆盖新草稿，revision 与请求签名不一致不能应用。非法数值明确提示，未解析字号或越界由后端报错。
- 默认就地显示未应用结果，不复制全篇或每段双份；可开启“对照原文”显示旧有上下对照。待更新/错误与真实未应用状态清晰，不能把旧帧当成最新结果提交。切换范围立即移除旧帧，按新范围重新预览；切到其他工作页保留草稿并暂停预览，回来自动继续。退出筛选不自动应用。
- 性能先用现有 content-visibility、请求合并/串行、较小响应及稳定组件渲染；测试真实 462 段与生成长文档，记录后端时间/响应体。指标不等同浏览器帧率，不宣称 20,000 段一定流畅。遇到实测瓶颈再作针对优化。

## 分页与导出

page_break_before 与 keep_next 同时开启在单个标题上有效：新页起始并连接随后正文。真正需要解释的是相邻段落 A keep_next 与 B page_break_before 冲突。基于最终候选有效格式（含原文继承和规则）检查直接相邻段落；当前更改涉及此边界才提示，列示具体编号。不自动取消用户输入或禁止合法组合，不承诺浏览器复现 Word 分页。不同表格单元格不误判为相邻连排。

导出标准是保存的原始 DOCX 和当前已应用的格式覆盖。允许被设置的段落格式变化；校验未选段落 XML、文字/域指令/数学文本、其他 ZIP 项以及剔除受支持格式节点后的结构。发现文字丢改、对象/表格结构破坏或范围外修改则停止下载。并非按未提交草稿或视觉审美检查，也不验证页数。当前归一化会忽略完整的 ind/spacing/rFonts 等支持节点，因此不是每个 OOXML 属性逐项白名单证明，保留此边界说明。

## F2 模板设计待落实

- 模板按段落类别匹配；按当前文档应用一次并可撤销，不持续绑定筛选器，不引用段落/章节 ID，不因标题移动而报错。
- “从此文档提取”按类别统计整套可支持的格式组合出现次数，取最常见的真实组合，避免逐属性众数拼出从未出现的组合。并列需明确显示候选/建议，不悄悄随机选。保存前列出同类不一致和频次；未知或混合行内属性不伪造，明确省略或允许用户指定。段落为应用单位，特殊行内字体的保留策略在 F2 开工细化。
- 多级标题/列表目前已有原始大纲/编号 level 元信息，但尚无独立的多级语义类别编辑。模板设计预留 role+level，不急于把 9 级标题和多级列表塞满所有普通类别下拉；后续面向用户可显示“一级标题”等独立项，同时保留“所有标题”筛选能力。最终建模在 F2 或专门阶段定稿。
- 旧规则不能直接抹除。需要冻结当前有效显示结果、保留兼容读取/历史恢复与迁移记录，不让格式突然回退；迁移方案、全局模板存储/导入导出/命名范围一起实施和测试。

## 验证与交付要求

检查连续字号步进与反向/净零、绝对替换、混合值；预览竞态/取消/退出/非法输入/提交新鲜度/成功清空；单组折叠不能隐式排除提交；分页边界与表格隔离；原 DOCX/未选段落保留和预览只读。运行适当后端与前端测试、Ruff/构建，记录性能与真实文档只读验证。浏览器既有策略限制不绕过，不声称实际视觉检查。
