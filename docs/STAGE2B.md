## 行为与边界

格式顺序固定为「原 DOCX → 启用的规则（列表从上到下）→ 本项目局部覆盖」。后面的规则只覆盖自己填写的属性；单次格式修改仍是局部覆盖，优先于全部规则。类别、标签、结构位置、文本、ID 是筛选条件，格式不参与匹配，避免循环依赖。标注改变后重新匹配规则。

规则是当前项目的持续定义，不把结果写回局部覆盖。禁用、删除或调整顺序后，从原文件重新计算，因此可恢复下层格式和混合文字格式。规则最多 50 条，名称不重名。零命中或被局部覆盖的规则也可保存，界面说明影响数量。全局模板继续后置；含 ID 的范围不能跨文件套用。

## 实现分解

1. **领域与持久化**：新增规则模型和纯规则投影模块，集中计算有效格式、各属性来源及规则命中统计。项目升级 v3，兼容 v1/v2；撤销快照、项目包去重、导入校验覆盖规则。规则及批量标注事务均校验 revision，原文件不变。
2. **规则操作**：新建/修改规则使用独立编辑草稿，复制当前筛选为条件，草稿与批量格式隔离。规则面板展示条件、格式、启用状态与顺序。新增/修改先预览后保存；启停、删除、移动作为明确可撤销操作直接保存。预览冻结请求及修订，逐段展示完整计算后的前后差异，能正确呈现删除属性和恢复继承。
3. **来源解释**：对象页逐属性展示原来源、命中规则层和最终胜出层。局部覆盖可逐项清除，明确仅清除本项目设置，不清除原 Word 内的直接格式。后续更完整的 Word 继承读取仍为 2C。
4. **批量标注**：在当前筛选范围内增删一个标签、设置类别或恢复自动类别。提交前一次性确定 ID，随后原子修改；不因为修改后的重新匹配继续扩大范围。保留未涉及的标签和格式，失败时无部分提交。
5. **快捷入口**：阅读区对象右键弹出横排动作和基本属性，可检查对象、调整此段格式或切换框选；查看对象从不加入批量范围。支持 Esc、外部点击关闭及视口边界约束。
6. **导出**：领域层得到规则与局部设置合成后的有效补丁，仍交给原 DOCX 定点写入器。未命中且无覆盖的段落不写；规则撤回后使用原始 XML，不反向猜测旧值。
