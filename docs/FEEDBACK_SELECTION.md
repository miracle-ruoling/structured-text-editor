# F1 补充反馈：直接选择与格式状态

2026-10-21，基线 dedf1ce。本轮只收尾 F1，不进入模板 F2。以下为实施前决策，交付结果补在文末。

## 交互与边界

- 中文斜体：现有全局 `font-synthesis: none` 会阻止缺少斜体字形的中文字体倾斜。只在文档正文允许合成斜体，保留原字体与逐 run 格式；不改 DOCX 写入逻辑，不用整个段落 transform 冒充斜体。
- 格式开关当前是操作草稿，应用后清空是有意设计。增加只读的当前状态投影：空草稿选项显示“开启 · 当前”“关闭 · 当前”“混合 · 保持各自”或“未解析 · 保持原样”。实际值仍为空，不把显示值写入草稿；只有用户选择开启/关闭才提交。粗体、斜体与分页开关一致处理，混合行内属性不能误报统一值。
- 去掉框选工具栏、复选框和临时框选集合，“批量操作”改为“操作”。检查焦点与实际范围仍独立。
- 未筛选时点击可编辑段落，立即建立直接选择的 ID 条件，并显示操作页。在直接选择状态，普通点击替换为另一段；Ctrl 点击向同一条件添加段落（去重，不切换取消）。避免第一次点击生成条件后，普通点击就再也不能换段的陷阱。直接选择与自定义筛选在范围栏显示不同名称。
- 编辑条件、选择预设、恢复已保存筛选后进入自定义筛选状态。普通点击只移动查看焦点，保持当前工作页和条件；焦点灰色且优先级低于绿色匹配、蓝色预览。无筛选时查看只读段落仍可打开对象页，不能加入操作范围。完整对象检查通过对象页或右键入口。
- 自定义筛选中 Ctrl 点击创建一个 ID 条件；同一次持续按住 Ctrl 的点击加入同一条件，松开 Ctrl、窗口失焦、切换工作页、退出/修改筛选或切换文档即结束本组。下次按住建立新条件。兼容 Meta；原快照不被后续手势改写。重复点击仅去重，不移除。
- 新条件遵守现有 all/any；高级模式追加 AND 并保留原表达式括号。提示“全部条件”为交集、扩展范围需选任一/OR，不能悄悄改变现有逻辑。显式“全部内容”（空 AND）仍是有效自定义范围。条件上限 30，失效表达式不能意外降级全选。
- 右键“此段格式”强制进入该段直接选择；“加入条件”提供无修饰键的可访问入口，相当于一次独立 Ctrl 手势。已有项目里的 ids 快照继续读取与删除，不迁移数据。
- 切换范围使旧预览立即失效。保留 F1 格式草稿/应用/取消契约，不自动应用，不取消文档切换和未提交标签的保护。

## 实现和检查

选择会话集中在 lib/selection.ts：新增直接选择来源与本次 Ctrl 条件 key，提供纯状态转移；App 接入按键释放/失焦与段落点击，不在组件或 UI 重写后端筛选真值逻辑。DocumentCanvas / SelectorBuilder / 快捷菜单统一删除旧框选概念并明确显示范围状态。

自动检查覆盖直接点选/换段/扩选、同次与分次 Ctrl 手势、自定义点击不改条件、快照不被重写、退出恢复/全选/只读/条件上限/高级表达式、预览新鲜度和应用后草稿清空；开关覆盖统一、混合、未知及行内差异。运行现有后端保留与状态回归、前端检查和生产构建。浏览器本轮重试仍遭权限策略拒绝，不绕过、不声称实际视觉验证。
