# 阶段 3A：原生写作最小闭环

2026-10-21 用户授权推进计划中的下一阶段。阶段 3 拆成可分别验收的交付；本轮完成 3A 后停止，不自动进入 3B。

## 本轮范围

- 新增独立原生写作入口，保留已有 DOCX 格式工作台及其未提交状态。
- 使用 Tiptap/ProseMirror 编辑正文、一级至三级标题，支持回车拆分、退格合并、段落删除和标题 Markdown 输入习惯。暂不支持行内富文本、列表、表格、图片。
- 段落使用 UUID 持久 ID，拆分/复制后只给新增节点分配新 ID；重排、保存、重开及历史恢复保留 ID。
- 独立原生项目 schema v1，严格校验节点与大小，不把原生内容伪装成 v5 原包项目。自动保存串行执行，revision 冲突保留本地输入并显式报错，不自动覆盖服务端。
- 内容和文档名共同进入服务端最近 50 次历史；快捷键与按钮使用同一历史。保存期间可继续输入；撤销、切换和导出先完成待保存内容，失败即停止操作。
- 原生 JSON 备份导入/导出、最近文档重开、适配器生成独立 DOCX（正文与标题）。源 DOCX 保真修改路径不参与原生写作。
