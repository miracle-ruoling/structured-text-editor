# 本次变化：持续点选与可编辑段落编号

2026-10-21。本轮只需查看最近的点选变化，不重复检查历史功能。新版含后端接口，先关闭旧服务、重新运行根目录 Start.cmd，再刷新页面；自动重启命令被审批策略拒绝，尚未执行。

- 无论是否已有筛选，Ctrl/Meta 点击都切换该段是否选中；松开后继续点选仍合并到原来的点选项。普通点击沿用之前的区别：直接选择时换段，自定义筛选时只移动灰色查看焦点。
- Ctrl 再点已选段落会取消。只靠点选加入的段落从“点选 是”中移除；仍被类别等条件命中的段落用“点选 不是”排除。增加和排除各自合并一项。复杂表达式必要时自动显示 AND/OR 关系，手写表达式中不同逻辑位置的旧点选项不会强行合并。
- “x 段快照”改成可编辑编号，例如 `3 5 8`。只接受数字和空格，回车或失焦后校验、去重；无效/只读编号报错，空输入不会变成全选。悬浮或聚焦编号框显示完整内容，原折叠列表已移除。
- 选择请求期间保留其他段落的高亮，只即时增删本次点击的段落；待新范围确认后才允许应用，避免误用旧范围。右键入口同步改成“切换此段选择”。
