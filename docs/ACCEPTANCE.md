## 模板的使用方式

- **从当前文档提取**：按正文、小标题、列表等现有类别，统计整套格式组合，建议最常用的一套。同类有差异会展示频次；最高频并列时，自行选择组合或不提取此类别。混合、未知及暂不支持的属性会省略，不替你猜默认值。
- **空白模板 / 编辑模板**：添加需要的类别，在各类别内展开文字、段落等格式分组。保存到本机模板库后，其他文档也能使用。支持另存新模板、JSON 导入导出、删除与最近删除恢复。
- **实时预览 / 应用**：默认匹配全文中模板包含的类别，也可限定到「当前筛选」，以排除特殊标签、表格等。预览就绪后应用，整笔操作可撤销；以后改变类别或标签不会自动重排。小标题和列表暂不细分级别。
- **保存与应用分开**：保存模板只更新模板库；应用只更新文档。应用后关闭预览以看清已保存结果，模板编辑稿保留；未保存的模板编辑会在离开时提示。未设置的文字属性保持原状，明确设置某属性会统一该段的该属性，混合文字覆盖会在应用提示中列出。

旧项目打开时会将规则在当前状态和每个撤销/重做状态中的结果分别冻结，保留局部格式优先级；旧规则完整留档，撤销不会重新开启持续规则。新的 `.sdoc` 为 v5，携带已应用结果和历史；全局模板库需要单独导出或随 data 目录备份。
