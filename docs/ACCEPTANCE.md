## B. 类别和标签

1. 点击编号 03 的正文，切换到对象属性。
2. 主要类别改为「引用」，添加「待检查」标签，保存标注。
3. 预期默认正文筛选数量由 5 变为 4；左侧出现引用类别统计。
4. 批量操作中删除其他条件，仅保留「标签 是 待检查」，预期只匹配该段。
5. 撤销标注，预期类别和标签恢复；不应影响之前独立的格式操作。

## C. 其他格式

1. 选择所有小标题，进入「文字」，点击「四号 14」。
2. 预览、应用，检查只有小标题字号变化。
3. 选择表格内文字，设置居中、段后 0 磅，检查表格以外不受影响。
4. 组合两个互斥条件，应显示 0 匹配并禁用格式应用；改成「任一条件」后应正常匹配并集。

## D. 保存与恢复

1. 保存项目包，刷新页面，确认已经应用的格式和标注仍在。
2. 导入保存的 `.sdoc`，确认类别、标签、格式和撤销历史都在。
3. 打开新示例后，通过「打开最近文档」切回先前项目。
4. 预览期间刷新页面，预期不会把预览草稿当作已应用修改。

## E. 真实 Word 文件

1. 导入一份自己的 `.docx`，先检查自动分类，修正未知或错误类别。
2. 选择正文，排除表格和例外标签，设置首行缩进并导出 Word。
3. 在 Word 中确认内容、图片/公式、表格与页眉页脚保留，且选中范围准确。
4. 注意：字号/行距变化会引起重新分页，这是实际排版变化；本工具不承诺页面像素一致。
